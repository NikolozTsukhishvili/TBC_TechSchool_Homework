# Full Stack დეველოპმენტი AI-ის დახმარებით — Landing Page

თანამედროვე, ადაპტური (Responsive) Landing Page კურსისთვის „Full Stack დეველოპმენტი ხელოვნური ინტელექტის დახმარებით“, შექმნილი AI აგენტის გამოყენებით.

## სექციები

- **Hero** — მთავარი სათაური, აღწერა, CTA ღილაკები და სტატისტიკა
- **About** — ინფორმაცია კურსის შესახებ
- **Features** — 3 ბარათი კურსის უპირატესობებით
- **Contact** — საკონტაქტო ინფორმაცია და ვალიდაციით აღჭურვილი ფორმა

## ტექნოლოგიები

- **HTML5** — სემანტიკური ტეგები (`header`, `nav`, `main`, `section`, `article`, `address`, `footer`)
- **CSS3** — CSS ცვლადები, Flexbox, Grid, Media Queries, ანიმაციები
- **JavaScript (Vanilla)** — ფრეიმვორკების გარეშე

## ფუნქციონალი

- ადაპტური დიზაინი (breakpoint-ები: 992px, 768px, 480px)
- მობილური ბურგერ-მენიუ
- აქტიური ნავიგაციის ლინკის მონიშვნა სქროლისას
- Scroll-reveal ანიმაციები
- საკონტაქტო ფორმის ვალიდაცია ქართული შეცდომის შეტყობინებებით
- ხელმისაწვდომობა: `aria-*` ატრიბუტები, კლავიატურით ნავიგაცია, `prefers-reduced-motion`

## გამოყენებული Prompt

**როლი:**
შენ ხარ გამოცდილი Frontend დეველოპერი, რომელიც წერს სემანტიკურ, სუფთა და ხელმისაწვდომ (accessible) კოდს.

**კონტექსტი:**
მჭირდება Landing Page კურსისთვის „Full Stack დეველოპმენტი ხელოვნური ინტელექტის დახმარებით“, რომელიც განკუთვნილია ნულოვანი გამოცდილების მქონე მოზარდებისთვის. გვერდის ენა — ქართული.

**დავალება:**
შექმენი თანამედროვე, ადაპტური (Responsive) Landing Page შემდეგი სექციებით:
1. **Header** — ლოგო და ნავიგაცია (მობილურზე ბურგერ-მენიუ).
2. **Hero** — მთავარი სათაური, მოკლე აღწერა, CTA ღილაკები.
3. **About** — ინფორმაცია კურსის შესახებ.
4. **Features** — ზუსტად 3 ბარათი კურსის უპირატესობებით.
5. **Contact** — საკონტაქტო ინფორმაცია და ფორმა (სახელი, ელ-ფოსტა, შეტყობინება).
6. **Footer** — საავტორო უფლებები.

**ტექნიკური მოთხოვნები:**
- მხოლოდ HTML, CSS და Vanilla JavaScript (ფრეიმვორკების გარეშე).
- ფაილების სტრუქტურა: `index.html`, `css/style.css`, `js/script.js`.
- სემანტიკური ტეგები: `header`, `nav`, `main`, `section`, `article`, `footer`, `address`.
- CSS ცვლადები, Flexbox და Grid; Mobile-friendly breakpoint-ები (992px, 768px, 480px).
- JS ფუნქციონალი: მობილური მენიუ, აქტიური ლინკის მონიშვნა სქროლისას, Scroll-reveal ანიმაციები, ფორმის ვალიდაცია შეცდომების ჩვენებით.
- ხელმისაწვდომობა: `aria-*` ატრიბუტები, `label`-ები, კლავიატურით ნავიგაცია, `prefers-reduced-motion`.

**შედეგის ფორმატი:**
სრული, გამართული კოდი თითოეული ფაილისთვის, მოკლე კომენტარებით სექციების გამოსაყოფად.
